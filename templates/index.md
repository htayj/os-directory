# Record Templates

These `.md.template` files are copyable authoring aids, not OKF concept
documents. Rename a copy so its final filename ends in `.md`.

* [Operating system](operating-system.md.template) - A named system lineage.
* [Operating-system release](operating-system-release.md.template) - A particular release or version.
* [Software artifact](software-artifact.md.template) - A surviving image, source tree, distribution, or binary.
* [Organization](organization.md.template) - A responsible institution or group.
* [Hardware platform](hardware-platform.md.template) - A machine family or architecture.
* [Source](source.md.template) - A bibliographic or archival source.
