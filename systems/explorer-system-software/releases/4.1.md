# Overview

Texas Instruments distributed release 4.1 as a bootable tape containing a load
band and separate microcode bands for Explorer I and Explorer II.

# Changes

Documented goals included compatibility with release 3.2, extended-address-space
support, remote tape, and simultaneous monochrome and color display support.
The release notes separately enumerate kernel, window-system, user-interface,
development-tool, I/O, and networking changes.

# Distribution

Release 4.1 was delivered on bootable tape. The Explorer LX upgrade path also
required Explorer LX 3.0 and TI System V 2.2.0 or later.
