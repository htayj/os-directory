# Multilingual Supplemental Discovery

This inventory compares native-language operating-system lists, categories,
institutional histories, and project sources against the frozen English-list
baseline.

The first release covers Arabic, Chinese, Czech/Slovak, French, German,
Italian, Japanese, Korean, Portuguese, and Spanish sources, in addition to the
separate Russian/Elbrus hardware-ecosystem pass.

Files named `<language>-candidates.json` preserve language-specific discoveries
and exclusions. `candidates-normalized.json` merges cross-language identities;
`manifests/`, `results/`, and `batches.json` track creation of supplemental
system records.

An entry being absent from the English list is a discovery fact, not evidence
that it is a distinct operating system. Releases, aliases, specifications,
hardware, fictional systems, and unresolved labels remain in the inventory.
