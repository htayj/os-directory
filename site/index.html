How to read this table

“Documented” relationships use contemporary manuals, official documentation, or similarly strong sources. “Provisional” relationships are discovery claims that still need primary-source confirmation. “No evidence found” means the automated pass did not locate a qualifying relationship; it does not mean the system had no editor.
